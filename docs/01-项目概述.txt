PawStay 宠物寄养 —— 项目概述（课程精简版）
====================================

一、产品定位
------------
面向宠物寄养机构的课程项目 Web 系统，对应课题四模块：
  1. 宠物及主人管理
  2. 寄养房间管理
  3. 预约与订单管理（含支付状态）
  4. 寄养服务与评价

产品由两部分组成：
  官网（顾客端）    查房、预约、一键支付、取消、查看护理动态、评价
  门店后台（/store/）按四模块管理主人宠物 / 房间 / 订单 / 护理评价


二、技术选型
------------
  形态        Web（B/S），桌面与手机浏览器自适应
  语言        Python 3.13
  框架        Django 6.1（官网自研模板，后台 Django Admin）
  前端        Bootstrap 5.3 + Bootstrap Icons（本地托管）
  数据库      MySQL 8+（utf8mb4）
  支付        沙箱一键已付（演示环境，无真实渠道）
  包管理      uv
  命令入口    GNU Make


三、系统模块
------------
  apps/pets           宠物主人与宠物档案
  apps/rooms          寄养房间与按晚报价
  apps/bookings       订单、空房校验、收退款流水
  apps/care           护理记录与服务评价
  apps/payments       沙箱一键支付
  apps/stores         单店模型（房间/订单归属）
  apps/web            官网与个人中心
  apps/security       账号辅助（课程版注册为手机号+密码）
  apps/notifications  遗留 app（未接入业务）


四、用户角色
------------
  宠物主人   官网注册，管理宠物、预约、支付、评价
  前台/护理  后台「前台」「护理师」权限组：办理入住离店、登记护理
  管理员     超级用户：房间与全部业务数据
