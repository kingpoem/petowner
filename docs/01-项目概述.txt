PawStay 宠物寄养 —— 项目概述
====================================

一、产品定位
------------
面向宠物寄养门店的一站式 Web 应用，解决三类问题：
  1. 主人端：找房难、价格不透明、寄养期间看不到宠物状况；
  2. 门店端：房间分配靠人工记忆、超订与漏单、收退款对不上账；
  3. 服务端：护理过程无记录、异常情况沟通不及时、口碑难以沉淀。

产品由三部分组成：
  官网与会员中心    宠物主人自助查房、预约、支付、改期、取消、查看护理动态、评价
  员工手机工作台    前台与护理师在手机上办理入住离店、收款、拍照登记护理记录
  运营后台          店长与管理员管理房间、价格、订单、收退款、评价，查看经营报表


二、技术选型
------------
  形态        Web（B/S 架构），桌面与手机浏览器自适应
  语言        Python 3.13
  框架        Django 6.1（官网为自研模板，后台基于 Django Admin 深度定制）
  前端        Bootstrap 5.3 + Bootstrap Icons（本地托管，无外部 CDN 依赖），
              自研中文日期选择器与灯箱，原生 JavaScript，无构建步骤
  数据库      MySQL 8+（字符集 utf8mb4）
  缓存        Django 数据库缓存（登录限流、验证码、短信频率）
  图片        Pillow（上传压缩、去 EXIF、WebP 缩略图），segno（二次验证二维码）
  短信        阿里云短信服务（开发环境打印到日志）
  部署        Docker Compose：Gunicorn + Nginx + MySQL + 定时任务 + 自动备份容器
  CI          GitHub Actions：lint、测试、部署检查、镜像构建
  静态文件    WhiteNoise（压缩 + 指纹文件名，长缓存）
  包管理      uv
  命令入口    GNU Make
  代码规范    ruff（lint + format）

选型理由：
  1. 业务以“表单 + 规则校验 + 后台管理”为主，Django 自带 ORM、表单、权限、后台与
     安全中间件，能以较少代码交付完整、安全的商业系统。
  2. 主人-宠物-订单-房间-护理-收款关系明确，适合关系型数据库；行锁与事务保证并发
     预约时不超订。
  3. Web 形态无需安装，手机浏览器即可使用，后续可平滑扩展微信小程序 / App。


三、系统模块
------------
  apps/pets           宠物主人与宠物档案（体型、性格、疫苗、驱虫、饮食、过敏）
  apps/rooms          寄养房间、节假日价格规则、逐晚报价计算
  apps/bookings       订单、可用房间校验、收退款流水、改期与违约金、候补队列、
                      超时取消任务、经营报表
  apps/care           护理记录（含照片、进食、健康状况）与服务评价
  apps/notifications  站内通知
  apps/security       图形验证码、短信验证码、登录限流、TOTP 二次验证、部署安全检查项
  apps/staff          员工手机工作台
  apps/web            官网、会员中心、账号体系、健康检查
  apps/images.py      上传图片处理与缩略图


四、目录结构
------------
  config/                 Django 配置（settings、urls、wsgi）
  apps/                   业务应用
  templates/              页面模板（web/ 官网，admin/ 后台定制）
  static/                 样式、图标、图片（img/stock 为授权图片及 credits.json）
  scripts/                辅助脚本（make help、图片下载、部署检查）
  deploy/                 Nginx 配置、容器入口脚本、备份脚本
  .github/workflows/      持续集成
  docs/                   项目文档与截图
  Dockerfile / docker-compose.yml   生产镜像与编排
  Makefile                一键命令
  pyproject.toml / uv.lock  依赖声明与锁定
  .env.example            环境变量模板


五、用户角色
------------
  宠物主人   官网注册（手机号 + 短信验证码），管理宠物、预约、支付、改期、取消、评价、
             查看通知
  前台       “前台”组：手机工作台办理入住离店与收款；后台管理主人/宠物/订单/候补/评价
  护理师     “护理师”组：手机工作台查看在住宠物，拍照登记护理记录
  管理员     超级用户：房间、价格规则、经营报表、账号权限等全部功能
  员工账号均需绑定身份验证器（生产环境），登录后台或工作台时输入动态码。
