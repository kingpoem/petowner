PawStay 宠物寄养 —— 开发与运行（课程精简版）
====================================

一、环境
--------
  Python 3.13、uv、GNU Make、MySQL 8+


二、本地启动
------------
  make seed    # 依赖、建库、迁移、演示数据
  make run     # http://127.0.0.1:8000/
  make test    # 单元测试
  make help    # 全部命令

  管理员：/admin/  → admin / admin123
  顾客：  登录页   → 13800000001 / pawstay123

  详见 docs/LAUNCH.md 与 README.md。
  开发环境短信验证码打印在 make run 控制台（SMS_BACKEND=console）。


三、常用命令
------------
  make migrate       迁移
  make reset-demo    清空后重新种子
  make expire        取消超时未支付订单
  make check         Django 检查 + 迁移完整性


四、配置
--------
  复制 .env.example 为 .env。
  课程默认 PAYMENT_SANDBOX=true（沙箱支付，无需真实商户号）。
