PawStay 宠物寄养 —— 开发与运行（课程精简版）
====================================

一、环境
--------
  Python 3.13、uv、GNU Make、MySQL 8+


二、本地启动
------------
  make seed    # 依赖、建库、迁移、演示数据
  make run     # http://127.0.0.1:8000/
  make test    # 单元测试
  make help    # 全部命令

  门店管理员：登录选「门店」→ /store/ → admin / admin123
  门店前台：  13900000001 / pawstay123
  门店护理：  13900000002 / pawstay123
  顾客：      登录选「顾客」→ 13800000001 / pawstay123

  详见 docs/LAUNCH.md 与 README.md。


三、常用命令
------------
  make migrate       迁移
  make reset-demo    清空后重新种子
  make check         Django 检查 + 迁移完整性


四、配置
--------
  复制 .env.example 为 .env。
  支付为课程沙箱一键已付，无需微信/支付宝密钥。
