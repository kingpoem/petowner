PawStay 宠物寄养 —— 功能说明（课程精简版）
====================================

  官网          http://127.0.0.1:8000/            顾客 13800000001 / pawstay123
  门店后台      http://127.0.0.1:8000/store/     管理员 admin / admin123
  健康检查      http://127.0.0.1:8000/healthz


一、官网（未登录可访问）
------------------------
1. 首页：品牌介绍、查空房、精选房间、公开评价。
2. 房间列表 /rooms/：按宠物类型、房型、日期筛选可订房间与报价。
3. 房间详情：设施介绍与按晚计价说明。


二、账号
--------
  注册 / 登录均可选择「顾客」或「门店」身份。
  顾客：手机号 + 密码，进入个人中心；门店：进入 /store/ 后台。
  找回密码走邮件或联系门店。


三、顾客端主要功能
--------------------
1. 个人信息登记：姓名、联系方式、紧急联系人。
2. 宠物信息登记：档案增删改查（疫苗、饮食等）。
3. 房间查询：按日期查空房；选定房间后生成订单并支付。
4. 寄养记录：历史与进行中订单；详情查看服务状态与护理进度。
5. 服务评价：寄养结束后评分与反馈。


四、门店后台（/store/）主要功能
------------------------
顶栏：顾客宠物 · 寄养房间 · 订单状态 · 日常服务 · 评价回复。
1. 顾客与宠物：查询主人/宠物档案与历史寄养。
2. 寄养房间：增删改查、列表改价、空闲/清洁/维护。
3. 订单状态：查单、查空房开单、收款、入住离店、取消。
4. 日常服务反馈：喂养护理与健康观察每日更新。
5. 评价回复：查看顾客评价并填写机构回复。


五、课题对应关系
----------------
  (1) 宠物及主人管理     → pets + 官网宠物页 + Admin
  (2) 寄养房间管理       → rooms + Admin
  (3) 预约与订单管理     → bookings + 预约/支付页 + Admin
  (4) 寄养服务与评价     → care + 订单详情护理线 + 评价页 + Admin
