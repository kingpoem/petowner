PawStay 宠物寄养 —— 功能说明（课程精简版）
====================================

  官网          http://127.0.0.1:8000/            顾客 13800000001 / pawstay123
  运营后台      http://127.0.0.1:8000/admin/      管理员 admin / admin123
  健康检查      http://127.0.0.1:8000/healthz


一、官网（未登录可访问）
------------------------
1. 首页：品牌介绍、查空房、精选房间、公开评价。
2. 房间列表 /rooms/：按宠物类型、房型、日期筛选可订房间与报价。
3. 房间详情：设施介绍与逐晚明细。


二、账号
--------
  注册 / 登录 / 找回密码（短信或邮件）；登录限流与图形验证码。
  个人资料：姓名、邮箱、地址、紧急联系人。


三、个人中心（/me/）
--------------------
1. 我的宠物：档案增删改查（编号、名称、品种、年龄、性别、健康、主人信息等）。
2. 在线预约 /book/：选宠物与房间、入住离店；自动校验空房与接待条件；生成订单。
3. 支付：沙箱或微信/支付宝；更新支付状态。
4. 订单：查询、改期、取消；详情展示护理动态。
5. 评价：寄养完成后填写评分、评价内容与意见反馈。
6. 站内通知。


四、运营后台（/admin/）
------------------------
1. 运营看板：今日入住/离店、在住概况。
2. 宠物主人、宠物档案、寄养房间（含价格与状态）。
3. 订单：入住/离店/收款/取消；房态日历。
4. 护理记录：喂养时间、护理内容、健康状态、服务人员（亦可通过订单内联登记）。
5. 服务评价回复。


五、课题对应关系
----------------
  (1) 宠物及主人管理     → pets + 官网宠物页 + Admin
  (2) 寄养房间管理       → rooms + Admin
  (3) 预约与订单管理     → bookings + 预约/支付页 + Admin
  (4) 寄养服务与评价     → care + 订单详情护理线 + 评价页 + Admin
